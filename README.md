# Atlas Travel: Front-end (React)

Réplica en React + TypeScript del diseño Figma **"Atlas – website"** (home desktop + mega menú "Destinos").

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

- Análisis del diseño, tokens, secciones e inconsistencias: [`docs/DESIGN_SPEC.md`](docs/DESIGN_SPEC.md)
- Prompt listo para continuar con Claude Code: [`docs/PROMPT_CLAUDE_CODE.md`](docs/PROMPT_CLAUDE_CODE.md)
- Reglas del proyecto para agentes: [`CLAUDE.md`](CLAUDE.md)
- Capturas Figma vs. React: `docs/reference/`

Stack:
- Vite, React 18 y TypeScript
- CSS Modules con design tokens
- Fuentes self-hosted (@fontsource)
- Sin dependencias de UI
